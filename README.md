# NumberGassingGame
A simple C# console game where the player guesses a randomly generated number within a limited number of attempts.

The computer chooses a random number, and the player tries to guess it within a limited number of attempts.

## How to play

1. Run the program.
2. Choose a difficulty level:
   - Easy: numbers from 1 to 10, 6 attempts
   - Medium: numbers from 1 to 25, 5 attempts
   - Hard: numbers from 1 to 50, 3 attempts
   - Custom: Choose your own maximum number and number of attempts
  

  
3. Enter your guess.
4. The game tells you if your guess is too high or too low.
5. Win by guessing the correct number before you run out of attempts.
6.  Choose whether to play again (`ja`/`nej`).

## Technologies

- C#
- .NET Console Application

## How to run

1. Open the project in Visual Studio or Visual Studio Code.
2. Build and run the program.
3. Follow the instructions in the console.
